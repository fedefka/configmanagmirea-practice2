## Установка и запуск
```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./run.sh
.venv/bin/python -m unittest discover -s tests -v
```
Для запуска нужны Python 3.9+ и PyYAML. Сборка не требуется.
В PyCharm можно запустить `src/main.py` с интерпретатором проекта.
## Настройки
Программа читает `config.yaml`. Другой файл можно передать первым аргументом.
| Поле | Назначение |
| --- | --- |
| `package` | Имя пакета, в тестовом режиме одна буква A-Z |
| `repository` | URL каталога для одной архитектуры Alpine или путь к тестовому файлу |
| `test_mode` | `false` для Alpine, `true` для тестового файла |
| `filter` | Подстрока имени пакета для исключения, пустая строка отключает фильтр |
Путь к тестовому файлу отсчитывается от папки файла YAML.
## Функции
`load_config` читает YAML. `check_fields` проверяет ключи и значения.
`check_url` проверяет URL. `repository_path` вычисляет путь к тестовому файлу.
`index_url` строит адрес индекса. `load_index` загружает его по HTTP.
`read_index` распаковывает gzip, `read_tar` читает APKINDEX из tar.
`parse_index` разбирает поля записей; `direct_requirements` читает поле D.
`main` читает настройки, загружает граф, сохраняет и открывает изображение.
## Пример
Запустите `./run.sh` с настройками по умолчанию для пакета `nano`.
В поле D могут быть имена пакетов, библиотек и виртуальных возможностей.
Отрицательные требования обозначают конфликты и не выводятся.
## Граф зависимостей
`get_repository` выбирает тестовый граф или данные Alpine. `read_test_graph`
читает строки вида `A: B C`. `provider_index` учитывает имена пакетов и поле p
APKINDEX. `split_requirement`, `version_key` и `matches` разбирают требования
и сравнивают версии. `resolve_requirement` находит подходящих поставщиков,
`package_neighbors` возвращает соседей пакета, включая неразрешённые требования.
`build_graph` обходит граф в ширину. `bfs_batch` обрабатывает один уровень,
`bfs_level` рекурсивно переходит к следующему. Глубина рекурсии ограничена
на одну серию уровней, поэтому длинная цепочка не переполняет стек.
В множество посещённых вершина добавляется при постановке в очередь.
Повторный переход остаётся ребром, но вершина второй раз не обрабатывается.
`print_graph` выводит список смежности. Фильтр исключает вершины и пути через них.
```sh
./run.sh examples/test.yaml
./run.sh examples/filter.yaml
./run.sh examples/isolated.yaml
```
Первый пример рисует цикл A -> B -> D -> A. Во втором D отсекается фильтром.
Третий пример рисует одну вершину F.
`reverse_edges` разворачивает рёбра исходного графа. Рекурсивный BFS
по обратным рёбрам находит прямые и транзитивные обратные зависимости.
## Визуализация
`mermaid_text` генерирует код Mermaid. `graph_layout` размещает вершины
по уровням BFS. `edge_curve`, `svg_edges` и `svg_nodes` рисуют рёбра и вершины;
`svg_text` собирает изображение. `save_graph` сохраняет оба файла в
`build/<пакет>/`, а `show_graph` открывает SVG в браузере.
```sh
./run.sh examples/nano.yaml
./run.sh examples/bash.yaml
./run.sh examples/curl.yaml
```
Флаг `--no-open` сохраняет файлы без открытия браузера.
Архитектура репозитория определяется URL, поэтому анализ работает и на macOS.
## Сравнение с apk dot
Сравнение выполнено отдельно на Alpine v3.22 aarch64 с apk-tools 2.14.13.
Использован один и тот же индекс каталога `v3.22/main/aarch64` на 13.11.2026.
SHA-256 индекса: `928e3b29349d9d3e4e39251d3f1e867b4e1dc60f7c073bf1f97516d57d02d64a`.
В `examples/reference` сохранён вывод штатной команды для каждого пакета.
| Пакет | Вершины | Рёбра программы | Рёбра apk dot |
| --- | --- | --- | --- |
| nano | 4 | 4 | 4 |
| bash | 11 | 20 | 20 |
| curl | 14 | 28 | 28 |
Сравнивались множества пар имён пакетов после снятия суффиксов версий.
Для всех трёх пакетов совпало каждое ребро. Форматы вывода отличаются:
apk dot подписывает версии и виртуальные требования, наш граф показывает имена.
Для bash оба графа учитывают несколько поставщиков `/bin/sh`.
Обход строит граф доступных поставщиков, без подбора набора для установки.
Ограничения версий проверяются для обычных числовых версий, суффиксов и ревизий.
Редкие варианты сортировки версий APK и несколько записей на имя не поддержаны.
Для повторной сверки в Alpine выполните:
```sh
repo=https://dl-cdn.alpinelinux.org/alpine/v3.22/main
for package in nano bash curl; do
    apk --no-cache --repositories-file /dev/null -X "$repo" dot "$package"
done
```
[Описание apk dot](https://github.com/alpinelinux/apk-tools/blob/v2.14.9/doc/apk-dot.8.scd).
